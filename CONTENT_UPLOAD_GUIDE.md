## 📋 Step-by-Step Content Upload Guide

### STEP 1: Voice Recordings for Pronunciation Practice

**File Format:** MP3, WAV, or OGG  
**Naming Convention:** `word-or-phrase.mp3`

#### Where to Place:
```
📁 assets/audio/pronunciation/bengali/
   📁 letters/
      - ka.mp3
      - kha.mp3
   📁 words/
      - dhonnobad.mp3
      - bhalobashi.mp3
   📁 phrases/
      - shuvo-sokal.mp3
      - apni-kemon-achen.mp3
   
📁 assets/audio/pronunciation/hindi/
   📁 letters/
   📁 words/
   📁 phrases/
   
📁 assets/audio/pronunciation/english/
   📁 letters/
   📁 words/
   📁 phrases/
```

#### Naming Best Practices:
- ✅ **Good:** `hello.mp3`, `thank-you.mp3`, `how-are-you.mp3`
- ❌ **Bad:** `Audio 1.mp3`, `Recording (2).mp3`, `VID20231201.mp3`

#### Extra Naming Tip (Recommended)
- Letters: keep filenames short and consistent (e.g. `ka.mp3`, `kha.mp3`, `ri.mp3`)
- Words/phrases: use lowercase + hyphens (e.g. `dhonnobad.mp3`, `apni-kemon-achen.mp3`)

#### Recommended File Size:
- Individual words: 50-200 KB
- Short phrases: 200-500 KB
- Sentences: 500 KB - 1 MB

   - lecture-02-common-mistakes.mp4

#### Video Specifications:
- **Resolution:** 1280x720 (HD) or 1920x1080 (Full HD)
- **Format:** MP4 (H.264 codec)
- **Frame Rate:** 30 fps
- **Bitrate:** 2-5 Mbps
- **Audio:** AAC, 128-192 kbps

#### Video Length Recommendations:
- **Introduction videos:** 3-5 minutes
- **Lesson videos:** 10-20 minutes
- **Detailed tutorials:** 20-45 minutes
- **Practice sessions:** 5-15 minutes

## 💻 How to Use These Assets in Your Web Pages

### 1. Pronunciation Audio in HTML

```html
<!-- In pronunciation-practice.html -->
<div class="word-card">
    <h3>নমস্কার (Nomoshkar)</h3>
    <p>Hello/Greetings</p>
    <button onclick="playAudio('bengali/nomoshkar.mp3')">
        <i class="fas fa-play"></i> Listen
    </button>
    <audio id="audio-player">
        <source src="./assets/audio/pronunciation/bengali/nomoshkar.mp3" type="audio/mpeg">
    </audio>
</div>

<script>
function playAudio(filename) {
    const audio = document.getElementById('audio-player');
    audio.src = `./assets/audio/pronunciation/${filename}`;
    audio.play();
}
</script>
```

## 🔧 File Upload Commands (PowerShell)

### Copy Files to Correct Locations

```powershell
# Copy audio files
Copy-Item "C:\path\to\your\audio\files\*.mp3" -Destination ".\assets\audio\pronunciation\bengali\"

# Copy PDFs
Copy-Item "C:\path\to\your\pdfs\*.pdf" -Destination ".\assets\documents\practice-pdfs\bengali\"

# Copy videos
Copy-Item "C:\path\to\your\videos\*.mp4" -Destination ".\assets\videos\recorded-lectures\bengali\"
```

### Check What's Been Uploaded

```powershell
# List audio files
Get-ChildItem ".\assets\audio\pronunciation\" -Recurse

# List PDFs
Get-ChildItem ".\assets\documents\" -Recurse -Filter "*.pdf"

# List videos
Get-ChildItem ".\assets\videos\" -Recurse -Filter "*.mp4"
```
