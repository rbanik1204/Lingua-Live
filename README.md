# LinguaLive - Premium EdTech Platform

**Learn. Speak. Perfect — Live.**

A modern, premium web application for live learning and pronunciation practice. Master Bengali, Hindi, and English pronunciation through interactive live classes, AI-powered practice sessions, and downloadable recorded lectures.

---

## 🎯 Project Overview

LinguaLive is a production-ready EdTech platform designed to feel like a real SaaS product comparable to Udemy, Zoom, and Duolingo. Built with modern web technologies and premium UI/UX design principles.

## 🚀 Getting Started

### Quick Start

1. **Download/Clone** the project files
2. **Open** `index.html` in a modern web browser
3. **Navigate** through different pages:
   - Landing Page: `index.html`
   - Student Dashboard: `student-dashboard.html`
   - Live Class: `live-class.html`
   - Pronunciation Practice: `pronunciation-practice.html`
   - Recorded Lectures: `recorded-lectures.html`
   - Teacher Dashboard: `teacher-dashboard.html`

### No Installation Required
All dependencies are loaded via CDN:
- Tailwind CSS
- Font Awesome Icons
- Google Fonts (Inter)

## 🔧 Customization

### Colors
Modify gradient colors in HTML files:
```html
from-indigo-600 to-purple-600  /* Change to your brand colors */
```

### Typography
Change font in HTML head sections:
```html
<link href="https://fonts.googleapis.com/css2?family=YourFont:wght@...&display=swap">
```

### Content
Update text, images, and links directly in HTML files.
