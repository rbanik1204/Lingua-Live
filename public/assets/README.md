# Assets Folder

## Required Files

### UPI QR Code
**File:** `upi-qr-code.png`

**How to generate:**
1. Open your UPI app (PhonePe/GPay/Paytm)
2. Go to "Receive Money" or "Show My QR Code"
3. Take a screenshot or save the QR code image
4. Place it in this folder as `upi-qr-code.png`

**Specifications:**
- Format: PNG (recommended) or JPG
- Minimum size: 500x500 pixels
- Maximum size: 1000x1000 pixels
- File size: Keep under 500KB
